# 🤖 AI Chatbot with Memory

An AI chatbot built using **Streamlit** and the **Groq API**. The chatbot maintains conversation history during the session to provide context-aware responses.

## Features

- 💬 Conversation Memory
- ⚡ Powered by Groq
- 🤖 Llama 3.3
- 🎨 Modern Streamlit Interface
- 🗑 Clear Chat Button
